RAF DAA Practice What is this website?

What is this website?

RAF DAA Practice is an unofficial practice website designed to help you prepare for the Defence Aptitude Assessment (DAA).

What is it for?

The aim is to give you a place to practise the different sections of the DAA in a format that feels like a timed test, so you can become familiar with the questions and improve your speed and accuracy.

What is currently available?

The website is still being developed. Currently, the Work Rate section is the working practice test. The other DAA sections are shown so the site can be built up into a fuller practice tool over time.

Important

This is an unofficial practice tool and is not affiliated with, endorsed by, or connected to the Ministry of Defence or the Royal Air Force.
